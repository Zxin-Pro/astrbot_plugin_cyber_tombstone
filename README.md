# astrbot_plugin_cyber_tombstone 🪦

赛博墓碑 —— 自动检测群内长期潜水的群友，为其生成庄重又搞笑的"赛博墓碑"图片与悼词，体面送 TA「归于潜水」。

## 功能

- 📊 **消息统计**：监听群消息写入本地 SQLite（内存缓冲批量落库，每 100 条或每 5 秒 flush），统计群龄 / 发言数 / 最后发言
- 🪦 **墓碑生成**：黑底墓园风图片（R.I.P 金色大字 + 拱形墓碑 + 遗言 + 悼词），渲染失败自动降级 Markdown 文本
- 🤖 **LLM 悼词**：调用 AstrBot 当前 Provider 生成庄重中带幽默的悼词（30 秒超时降级本地模板）
- ⏰ **自动扫描**：每日到点扫描所有已记录群，为潜水超过阈值的群友自动立碑并推送（单群超 20 人只取沉默最久的 10 人，防刷屏）
- 🕯 **历史回溯**：`/墓碑 初始化` 通过 OneBot 接口拉取历史群消息回填数据库（游标断点续传，可多次执行向更早回溯）
- 🧹 **自动清理**：messages 原始消息默认保留 90 天，users 聚合表永久保留

## 指令

主指令 `tomb`（别名：墓碑 / 赛博墓碑）：

| 指令 | 说明 |
|---|---|
| `/tomb @某人` | 预览 TA 的墓碑（不立碑） |
| `/tomb bury @某人` | 正式立碑（记录在案） |
| `/tomb scan` | 扫描本群潜水名单 |
| `/tomb list` | 查看本群所有墓碑 |
| `/tomb revive @某人` | 复活（移出墓碑名单） |
| `/tomb forget @某人` | 删除 TA 的全部记录（隐私） |
| `/tomb forget_all` | 清空本群全部记录（仅管理员） |
| `/tomb config` | 查看当前配置 |
| `/tomb init`（初始化） | 回溯历史聊天记录，装插件前的发言也能统计 |
| `/tomb debug` | 墓园运行诊断 |

## 配置

| 键 | 默认 | 说明 |
|---|---|---|
| inactive_days | 30 | 潜水判定阈值（天） |
| auto_scan_enabled | true | 开启自动扫描 |
| auto_scan_time | "20:00" | 自动扫描时间 |
| push_target | "" | 推送目标群号（逗号分隔，留空发原群） |
| max_scan_results | 10 | 单次扫描最多返回人数 |
| enable_image_render | true | 启用图片渲染 |
| enable_record | true | 记录群消息（隐私开关） |
| message_retention_days | 90 | 原始消息保留天数 |
| history_max_count | 2000 | 初始化单次最多回溯条数 |

## 隐私说明

- 仅记录**群消息**，不碰私聊
- 所有记录仅存本地 SQLite，不上传任何第三方
- `/tomb forget @某人` 可彻底删除某人全部记录（消息 + 聚合 + 墓碑）
- `/tomb forget_all`（管理员）一键清空本群全部记录
